# Competition Radar 静态发布候选

此目录只包含审核后的静态产物，不包含完整开发工程或研究数据库。公开静态站不意味着完整项目源码开源；项目源码许可证尚未决定。第三方许可声明见 `site/third-party-notices.txt`。

来源数据截至日期与状态评估日期分别见 site/site-manifest.json 和 site/public-manifest.json。页面根据设备时间、已公布日期精度及赛道分别计算时间状态；时区不明的边界保持不确定。该判断不证明报名平台是否受理，也不自动发现延期；来源变更仍须经受控证据审核并重新发布。

`python3 tools/verify.py` 核验已审核 Manifest、每个静态文件和固定版本的 Node.js 时态行为检查。`--publish` 运行同样的完整性与行为校验，不以数据截至日期单独阻止修复发布。校验不能替代来源、版权和时效审查。

新页面对 JavaScript 和样式资源使用内容寻址路径，并保留上一已发布版本的无版本资源，减少新旧页面与资源混用。浏览器若继续使用已缓存的旧页面和旧脚本，仍会沿用旧版判断，直到获取新页面；请以最新官方公告为准。

Push 和 pull request 只运行只读校验。上传和部署只在默认分支手动运行、publish=true 且仓库变量 G1514_PAGES_DEPLOYMENT=enabled 时进行。环境保护须在 GitHub 上另行配置；公开创建、推送、Pages 配置和首次部署须事先获得所有者明确授权。部署只上传 site 目录。保留并核验上一版本和 Manifest，可经相同人工流程回滚。
